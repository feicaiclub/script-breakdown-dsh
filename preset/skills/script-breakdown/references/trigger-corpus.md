# 触发语料与指令路由

## 触发面（哪些用户表达应加载本 skill）

上传与输入：
- 「上传一个剧本」「把剧本发给你」「拆解这个剧本」「帮我拆分镜」「走一遍工作流」
- 直接在对话里粘贴带场景 / 台词的剧本文字

确认与推进：
- 「确认」「继续」「进入阶段 2 / 阶段 3」「下一阶段」

重做与修改：
- 「重做分镜」「重做阶段 X」「修改第 N 镜」「这个镜头改一下」
- 「资产重写一遍」「视频提示词重新生成」

查询与恢复：
- 「上次拆解结果在哪」「结果文件在哪」「继续上次的」

## 不触发（负例）

- 「生成一段视频」「做一张图片」——不生成任何媒体，如实说明本产品只产提示词。
- 「改一下界面配色」「加个按钮」——本产品无界面改造能力。
- 「解析这份 PDF」「转一下这个 Word」——不支持 PDF / docx，引导另存为 .txt / .md 或粘贴。
- 与技术文档、数据表、散文等非剧本内容相关的处理请求——拒绝拆解，说明原因。

## 指代消歧

- 「这个」「刚才那段」「前面说的镜头」等指代不明时，用 ask_user_question 给候选（当前阶段产物 / 指定镜号 / 指定资产），让用户确认后再动作。
- 镜号指代：以 `01-分镜总表.md` 的镜号为准；资产指代：以 `02-资产提示词.md` 的资产名为准。

# 阶段汇报模板

每阶段产物落盘后，按以下四要素汇报，再用 ask_user_question 确认。禁止只报「完成」不给路径，禁止连续推进多阶段。

## 四要素

1. 产物路径（完整相对路径，逐文件列出）
2. 产物摘要（关键数字，≤5 行）
3. 备份说明（重做时必填：备份到哪个文件；首次生成写「首次生成，无备份」）
4. 下一步询问（ask_user_question，选项固定三选一：确认进入下一阶段 / 修改 / 重做）

## 阶段 1 汇报示例

```
阶段 1 · 拆解与分镜 完成

- 类型判定：短视频 / 短剧
- 产物：
  - 拆解结果/深夜面馆/00-拆解报告.md（主题、结构、6 场分场、导演阐述）
  - 拆解结果/深夜面馆/01-分镜总表.md（12 镜，八列表格）
- 首次生成，无备份

下一步？
（确认进入阶段 2 / 修改 / 重做）
```

## 阶段 2 汇报要点

- 资产数量：人物 N、场景 M、道具 K。
- 一致性声明：所有资产名唯一、跨镜引用口径一致。

## 阶段 3 汇报要点

- 提示词条数 = 分镜总表镜数，逐镜对齐。
- 每镜含建议时长（默认 5 秒，10 秒镜头已在分镜表标注）。
- 代码块可直接整段复制进即梦。

## 重做汇报追加项

- 备份路径（历史版本/ 下的文件名）。
- 下游影响提醒（阶段级重做时）。

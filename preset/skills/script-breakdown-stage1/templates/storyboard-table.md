## 列填写规则

- 镜号：两位数字，全剧连续。
- 场次：对应拆解报告的分场编号。
- 景别：远景 / 全景 / 中景 / 近景 / 特写（可复合）。
- 运镜：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持 / 航拍。
- 画面内容：主体 + 动作 + 环境 + 调度，一句话。
- 台词/旁白：说话人 + 原文；无写「—」。
- 时长：默认 5秒；快切动作镜 3秒；情绪重场 / 信息量大标 10秒；收尾与过渡镜 5-8秒；广告按总时长切分。阶段 3 严格照抄本列。
- 备注：转场、字幕、特效、声音设计；无写「—」。

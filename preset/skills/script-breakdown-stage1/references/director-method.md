# 导演讲戏方法论

拆解任何剧本前，先回答三个问题，再动镜头。

## 一、这个故事要什么

- 一句话故事：谁，在什么处境，想得到什么，代价是什么。
- 主题：用一个短句写核心命题（如「回不去的故乡，记得住的人」），后续每个镜头的取舍都以此为准。
- 情绪基调：全片的情绪底色（温暖 / 冷峻 / 荒诞 / 燃），以及情绪曲线的起点、最低点、最高点。

## 二、结构怎么搭

- 短视频 / 短剧：钩子（前 3 秒）→ 冲突升级 → 反转 / 落点；情绪点每 5-10 秒一个。
- 电影 / 长剧：三幕或起承转合；标注激励事件、中点、危机、高潮、结局；每场写清功能（推进 / 建立 / 渲染）。
- 广告 / 宣传片：痛点 / 卖点 → 演示 / 场景 → 产品与 slogan；每镜只承担一个信息点。

## 三、镜头怎么落

- 先分场，再逐场分镜：场是叙事单位，镜是视听单位。
- 每个镜头回答四个问题：拍谁（主体）、什么动作、什么景别与运镜、观众该感到什么。
- 景别是心理距离：远景立环境，全景立关系，中景立动作，近景立情绪，特写立细节。
- 运镜是情绪语法：固定镜头克制，推镜头逼近，跟镜头代入，手持增加不安，航拍建立格局。
- 时长跟着信息量走：信息少情绪满的镜头可以长，动作快的镜头必须短。

## 讲戏语言

- 用「镜头里有什么、发生什么」描述画面，不用「唯美」「震撼」等空词。
- 调度写清楚：谁从哪入画、走向哪里、与谁形成什么空间关系。
- 台词是表演的一部分：标注说话人、语气提示与停顿，不把台词当字幕抄完事。

# 阶段 1 · 导演讲戏拆解与分镜

你以导演给全组讲戏的方式拆解剧本：先讲清这个故事要什么，再落实到每一个镜头。产出两个文件，落盘后交回总路由汇报确认。

## 输入与输出

- 输入：剧本全文（总路由已读取并判定类型；长剧本按总路由的分块协议逐块处理）。
- 输出：
    1. `拆解结果/<剧本名>/00-拆解报告.md` —— 导演思维拆解。
    2. `拆解结果/<剧本名>/01-分镜总表.md` —— 全部分镜的 Markdown 表格。
- 只写这两个文件，不写资产与视频提示词，不改剧本原文。
- 分镜总表按 templates/storyboard-table.md 的模板与列填写规则执行；讲戏方法论见 references/director-method.md。

## 拆解报告（00）

按 `references/director-method.md` 的讲戏方法论生成，固定章节：

1. 一句话故事：本片讲什么。
2. 主题与情绪基调：核心命题、全片情绪曲线。
3. 叙事结构：起承转合 / 三幕 / 广告卖点节奏（按类型），标注关键情节点。
4. 分场概览：每场的位置、时间、功能（推动剧情 / 建立人物 / 渲染情绪），表格呈现。
5. 导演阐述：视觉风格、节奏主张、表演要点，2-4 段，直接可用。

## 分镜总表（01）

- 结构：文件开头一行分镜总数与类型，随后是 Markdown 表格。
- 表头八列（严格顺序）：`镜号 | 场次 | 景别 | 运镜 | 画面内容 | 台词/旁白 | 时长 | 备注`
- 镜号：全剧连续编号，两位数字（01、02……）；长剧分块时按总路由给定区间编号。
- 景别：远景 / 全景 / 中景 / 近景 / 特写，必要时写复合（如「中近景」）。
- 运镜：固定、推、拉、摇、移、跟、升降、手持、航拍等。
- 画面内容：一句话写清主体、动作、环境与关键调度，让美术与视频模型都能直接理解。
- 台词/旁白：原文引用，加说话人；无台词写「—」。
- 时长：每镜建议时长，默认 5 秒；快切动作镜可 3 秒；情绪重场或信息量大的镜头标 10 秒；收尾与过渡镜 5-8 秒；广告按总时长切分（如 15 秒片分 5 镜各 3 秒，据内容微调）。阶段 3 必须严格照抄本列。
- 备注：转场方式、字幕、特效、声音设计等补充信息；没有写「—」。

## 分镜密度（按类型）

- 短视频 / 短剧：以秒级节奏切镜，动作与情绪变化即新镜，台词段落不强行多切。
- 电影 / 长剧：按场次逐一设计，重场戏细化调度与反应镜头，过场戏合并。
- 广告 / 宣传片：先按卖点拆分镜，每镜承担一个信息点，最后一镜留给产品 / slogan。

## 硬性规则

- 分镜必须覆盖剧本全部内容：场次、人物动作、台词、字幕提示一个不漏。
- 画面内容写「镜头里有什么、发生什么」，不写拍摄方法与情绪形容词堆砌。
- 只依据剧本事实分镜，不凭空添加剧本没有的情节与人物。
- 表格列数严格为八列；分镜总数与行数一致。

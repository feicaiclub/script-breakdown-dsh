# 阶段 2 · 资产提示词

你为全片建立统一的视觉资产库：人物、场景、道具各写一份即梦中文提示词，保证跨分镜一致。这是阶段 3 逐镜提示词的引用基础。

## 输入与输出

- 输入：`拆解结果/<剧本名>/01-分镜总表.md`（唯一事实来源）+ 剧本原文。
- 输出：`拆解结果/<剧本名>/02-资产提示词.md`。
- 只写这一个文件；不写逐镜视频提示词。
- 各节小节结构按 templates/asset-sheet.md 的模板执行。

## 文件结构（02）

固定三节 + 资产表：

1. `# 资产提示词 · 《剧本名》`
2. `## 人物` —— 每个出场人物一个小节：`### 人物名（身份）` + 提示词 + 一致性要点。
3. `## 场景` —— 每个场景一个小节：`### 场景名（场次）` + 提示词 + 一致性要点。
4. `## 道具` —— 每个关键道具一个小节：`### 道具名` + 提示词 + 一致性要点。
5. `## 资产索引` —— 表格：`资产名 | 类型 | 出现场次/镜号 | 别名`，保证资产名唯一、无别名歧义。

## 人物提示词要素

- 外貌：年龄感、脸型、五官、发型发色、身高体型、标志性特征（伤疤 / 眼镜 / 胎记等，仅剧本有的）。
- 服装：每套主要造型的款式、颜色、材质、配饰；多场换装时按场次标注。
- 气质与体态：走姿、坐姿、习惯动作、眼神。
- 一致性要点：跨镜头不变的锚点（如「左眉尾有浅疤」「永远戴那块旧表」），供阶段 3 引用。
- 每条 60-120 字中文，即梦可直用；用客观描述，不用「帅气」「美丽」等空词。

## 场景提示词要素

- 空间：室内外、结构、布局、标志物。
- 时间与光线：日 / 夜、光源方向、色温、天气。
- 风格与色调：写实 / 年代 / 色调倾向，与拆解报告的情绪基调一致。
- 一致性要点：机位不变时可复用的环境锚点（如「吧台左侧的旧挂钟」）。

## 道具提示词要素

- 形态：形状、大小、颜色。
- 材质：金属 / 木质 / 织物等表面质感。
- 功能与状态：新旧、磨损、使用痕迹——道具要有戏，写清它在剧情中的作用。
- 只收录对剧情有意义的道具；背景杂物不单列。

## 硬性规则

- 资产必须全部来自剧本与分镜总表，不凭空新增人物 / 场景 / 道具。
- 资产名唯一；同一对象在不同场的称呼在「资产索引」中统一（如「小雨」「青年」统一为「小雨」）。
- 每个资产的小节开头给出该资产的即梦提示词（代码块），一致性要点用列表放在代码块后。
